# Shorts 테스트: 문어의 놀라운 비밀 4가지 🐙

유튜브 쇼츠 업로드용 **30초 세로형(1080×1920, 30fps) 2D 애니메이션** 테스트 영상입니다.
그림·애니메이션·배경음악·효과음 모두 코드로 직접 생성했기 때문에 외부 저작권 소재가 없습니다.

- 완성 영상: [`output/octopus_short.mp4`](output/octopus_short.mp4) (H.264 + AAC, 30.0초, 약 16MB)

## 구성 (30초)

| 구간 | 내용 |
|---|---|
| 0.0–3.6s | 훅: "문어의 심장은 몇 개일까?" |
| 3.6–10.2s | 사실 1: 심장이 3개 (아가미 심장 2 + 온몸 심장 1) |
| 10.2–16.6s | 사실 2: 피가 파란색 (철 대신 구리 기반 헤모시아닌) |
| 16.6–22.6s | 사실 3: 헤엄칠 땐 온몸 심장이 멈춤 → 그래서 기어다니는 걸 선호 |
| 22.6–27.6s | 사실 4: 뉴런의 약 2/3가 다리에 있어 다리가 스스로 맛보고 판단 |
| 27.6–30.0s | 아웃트로: "신기하죠?" + 구독 버튼 |

## 다시 만들기

```bash
sudo apt-get install -y ffmpeg fonts-nanum
pip install -r requirements.txt
./make_short.sh
```

특정 장면만 PNG로 미리 보기:

```bash
python3 src/render.py --preview 2.5,7.5,18.3 --preview-dir build/preview
```

## 파일 구조

- `src/timeline.py` — 장면 타이밍, 효과음 큐 (영상/오디오 공용)
- `src/render.py` — pycairo로 프레임을 그려 ffmpeg로 인코딩 (멀티프로세스)
- `src/audio.py` — numpy로 배경음악(마림바·베이스·드럼·멜로디)과 효과음 합성
- `make_short.sh` — 전체 빌드 스크립트
