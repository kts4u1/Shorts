## 어떻게 만들었나

- **2D:** `src/render.py` — pycairo 벡터 드로잉으로 프레임을 그려 ffmpeg 로 인코딩
- **3D:** `3d/scene.js` — three.js 장면(문어, 모래 바닥, 물결 빛 무늬, 해초, 산호, 물고기, 3D 하트/핏방울/원그래프)을
  헤드리스 Chromium 에서 렌더링 → `src/composite3d.py` 가 2D 버전과 같은 자막/UI 를 합성
  - 문어 동작·표정·소품 타이밍은 `src/scene3d_state.py` 가 2D 와 같은 계산으로 넘겨주므로 두 버전이 똑같이 움직임
- **나레이션:** `src/narration.py` — [Supertone Supertonic](https://huggingface.co/Supertone/supertonic-3) 한국어 TTS(로컬 ONNX, OpenRAIL-M 라이선스)
  - 목소리 F2 + 음높이·음색 +2반음(`--pitch`), 말하기 속도 1.05 — 높고 발랄한 젊은 톤
    (TTS 를 느리게 합성한 뒤 재생 속도를 올려, 늘이기 처리 없이 음높이·포먼트를 함께 올림)
  - 대사마다 여러 번 합성해, 최종 영상과 같은 조건(음색 처리 + 배경음악)에서 자동 검사 후 선택:
    Whisper 받아쓰기(발음/누락), 끝 잘림, 말 도중 순간 끊김(드롭아웃)
  - 후처리: 날카로운 대역(2.5~4.5kHz, `--presence-db`)과 고역(`--shelf-db`)을 살짝만 줄이고 치찰음(ㅅ·ㅆ·ㅊ)을 동적으로 감소
    (너무 깎으면 목소리가 둔하고 나이 들어 들리므로 약하게)
- **음악/효과음:** `src/audio.py` — numpy 로 합성, 나레이션이 나올 때 음악·효과음을 자동으로 줄임(더킹), 대사 첫 음절 구간은 효과음을 추가로 줄임, 찌그러짐 없는 리미터로 마무리(약 -15 LUFS)
- **타임라인:** `src/timeline.py`(문어 편), `otter/timeline.py`(해달 편) — 장면, 나레이션, 효과음 타이밍.
  `narration.py`/`audio.py` 에 `--timeline otter/timeline.py` 를 주면 해달 편으로 동작

## 다시 만들기

```bash
sudo apt-get install -y ffmpeg fonts-nanum
pip install -r requirements.txt
./make_short.sh          # 전부 (2d / 3d / otter 인자로 하나만 가능)
```

다른 목소리로 바꾸기 (F1–F5 여성, M1–M5 남성, 섞기 가능):

```bash
python3 src/narration.py --voice "F2:0.75+F5:0.25" --pitch 2 --out build/narration.wav && ./make_short.sh
```

미리 보기:

```bash
python3 src/render.py --preview 2.5,7.5,18.3 --preview-dir build/preview
```
